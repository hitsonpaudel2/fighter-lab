# 🥊 FIGHTER LAB // Interactive Boxing & At-Home Conditioning App

**FIGHTER LAB** is a web application designed to give users customized, goal-oriented workouts at home—ranging from hyper-focused ab routines to full bodyweight conditioning and technical boxing progressions.

---

## 🔥 Features

- **Goal-Based Routine Generator:** Choose directly between:
  - 🏋️ **Abs Only:** Core hypertrophy and 6-pack isolation.
  - 💪 **Full Body (At-Home):** Pure bodyweight strength (Chest, Legs, Arms, Shoulders) without boxing.
  - 🥊 **Boxing Skills:** Stance, footwork drills, jab-cross mechanics, and combinations.
  - ⚡ **Boxing + Abs:** Total combat conditioning combining shadowboxing rounds with core circuits.
- **Interactive 2D Muscle Diagram:** SVG-powered anatomical model that dynamically highlights targeted muscle groups based on the selected routine.
- **Complete Prescriptions:** Every routine includes weekly frequency, duration, rest periods, exact sets, reps, and form tips.
- **Zero Equipment Needed:** Built specifically for home practice.
- **Cyberpunk Dark Mode UI:** High-energy, responsive design optimized for mobile and desktop screens.

---

## 🚀 How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in any web browser (Chrome, Safari, Firefox, Edge).
3. No build tools, packages, or servers required!

---

## 🛠️ Built With

- **HTML5** - Semantic structure and inline SVG graphics.
- **CSS3** - Custom flexbox/grid layout and CSS variables for high-tech themes.
- **Vanilla JavaScript** - Dynamic routine filtering and SVG DOM manipulation.

---

## 📌 Usage

1. Open the website.
2. Select your training goal at the top (*Abs*, *Full Body*, *Boxing*, or *Combo*).
3. Check the targeted muscles on the 2D figure on the left.
4. Follow the step-by-step sets, reps, and round timings on the right.
