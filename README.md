**FIGHTER LAB** is a high-performance web application built to guide users through custom, goal-oriented workouts at home—ranging from hyper-focused ab routines and full bodyweight strength training to technical boxing combinations and interval round timing.

---

## 🔥 Key Features

- **⏱️ Web-Audio Boxing Round Timer:**
  - Built-in interval timer with visual phase indicators (**WORK** vs. **REST**).
  - Synthesized fight bells and countdown sound effects powered by the native browser **Web Audio API** (zero external mp3 downloads required).
  - Quick-start fight presets: *3x3m Pro Boxing*, *4x2m Amateur*, and *5x45s HIIT Abs*.

- **🎯 Goal-First Routine Selector:**
  - 🔥 **Abs Only:** Isolation exercises for upper/lower core hypertrophy and oblique rotation.
  - 💪 **Full Body (At-Home):** Pure bodyweight strength for chest, shoulders, triceps, and legs. Zero boxing involved.
  - 🥊 **Boxing Skills:** Technical footwork drills, jab-cross mechanics, and 3-punch combination flows.
  - ⚡ **Boxing + Abs:** Hybrid combat conditioning pairing heavy shadowboxing rounds with fighter core circuits.

- **🧍 Interactive SVG Muscle Diagram:**
  - Dynamic 2D anatomical graphic that automatically highlights targeted muscle groups based on the selected workout routine.

- **📊 Complete Workout Prescriptions:**
  - Includes weekly frequency targets, estimated routine durations, rest periods, sets, reps, and practical form tips.

- **📱 High-Energy Cyberpunk UI:**
  - Fully responsive, mobile-first dark mode layout with custom neon accents.
